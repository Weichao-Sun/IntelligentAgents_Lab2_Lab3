# Tutorial 14 - Facing the Wall

This tutorial practice demonstrates simple wall collision in a Qt Widgets application.

## Main concepts

- QWidget subclass
- paintEvent()
- keyPressEvent()
- QPainter
- keyboard input
- wall collision detection
- update() repaint cycle

## Runtime result

The program opens a grid-based GUI window. The yellow player cell can be moved using the arrow keys. The player cannot move through black wall cells or outside the board.
