# Tutorial 13 - Game Over

This tutorial practice demonstrates a simple game-over state in a Qt Widgets application.

## Main concepts

- QApplication
- QWidget
- QLabel
- QPushButton
- QVBoxLayout
- signal-slot connection
- runtime score update
- game-over state

## Runtime result

The program opens a small GUI window with a score label and buttons. Clicking "Collect Cookie" increases the score. When the score reaches 30, the application displays a game-over message and disables the collect button.
